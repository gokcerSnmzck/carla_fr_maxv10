# CARLA FR-maxV10 Ackermann Robot Model

This repository contains the asset files for the **FR-maxV10** Ackermann-type robot model, fully compatible with **CARLA 0.9.16** packaged versions.

## Repository Structure
```text
carla_fr_maxv10/
└── CarlaUE4/
    └── Content/
        └── Carla/
            ├── Blueprints/Vehicles/FR-maxV10/  <- Blueprint assets
            ├──	Blueprints/Vehicles/            <- General Blueprint assets
            └── Static/Vehicles/FR-maxV10/      <- Static meshes & textures
```

## Installation Instructions
1. Download or clone this repository.
2. Copy the `CarlaUE4` folder and merge it directly into your root `CARLA_0.9.16` directory.
3. Launch the CARLA server.
